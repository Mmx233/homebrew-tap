# Mmx233 Tap

## How do I install these formulae?

`brew install mmx233/tap/<formula>`

Or `brew tap mmx233/tap` and then `brew install <formula>`.

| Formula        | Command   | Purpose                           |
|----------------|-----------|-----------------------------------|
| backoff        | `backoff` | Command retries and health checks |
| code-cli       | `code`    | Clone and open projects           |
| go-release-cli | `release` | Build and package Go programs     |
| heyfile-go     | `hey`     | LAN file sharing                  |
